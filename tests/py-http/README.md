# MikMongo API — Python HTTP Test Suite

Lightweight Python harness that hits the live MikMongo API based on
`docs/openapi.docs.yml`. Mirrors `tests/http/` (the Hoppscotch suite) but is
runnable directly from the command line, per file or all at once.

## Setup

```bash
cd tests/py-http
pip install -r requirements.txt
cp .env.example .env
# edit .env: set MIKMONGO_BASE_URL, MIKMONGO_EMAIL, MIKMONGO_PASSWORD
```

## Run

### Single file (standalone)
```bash
python test_01_auth.py          # logs in and caches the JWT
python test_07_invoices.py      # runs invoice read-only checks
```

### All files
```bash
python run_all.py
```

### With mutating tests enabled (dev/stage only)
```bash
MIKMONGO_DESTRUCTIVE=1 python run_all.py
```

### Verbose request/response logging
```bash
MIKMONGO_VERBOSE=1 python test_04_routers.py
```

### pytest (optional)
```bash
pytest tests/py-http/ -v
```

## How auth works

1. `test_01_auth.py` POSTs to `/api/v1/auth/login` using credentials from `.env`.
2. On success, the JWT is written to `.auth_cache.json` (gitignored).
3. Other test files load the token via `client.get_token()` which checks:
   - `MIKMONGO_TOKEN` env var
   - `.auth_cache.json`
4. If no token is available, requests are skipped with a warning.

```
  ✓ list invoices             GET /api/v1/invoices → 200
  ✓ list overdue              GET /api/v1/invoices/overdue → 200
  ⊘ trigger monthly           (destructive disabled)
```

Final summary: `7/8 passed, 1 skipped`. Non-zero exit code on any failure so
this can be plugged into CI.

## Files

- `config.py` — env loading + seeded UUIDs
- `client.py` — `ApiClient`, `Result`, `check`, `section`, `Tally`
- `run_all.py` — discovers and runs every `test_*.py`
- `.env.example` — template (copy to `.env`)
- `.auth_cache.json` — generated by `test_01_auth.py` (gitignored)

## Adding a new test file

```python
# test_99_my_domain.py
from client import ApiClient, section, check, print_summary
import config

def run():
    api = ApiClient()
    if not api.require_token("my_domain"):
        return
    section("My Domain")
    check("list things", api.get("/api/v1/things"))

if __name__ == "__main__":
    run()
    raise SystemExit(print_summary())
```

Drop it into the directory; `run_all.py` will pick it up automatically.
